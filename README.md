# CloudGGKEIT

Telegram-бот для учебных материалов. Откройте личный чат и нажмите «Начать». Кнопка «Загрузить» позволяет редактору выбрать предмет и прикрепить документ до 20 МБ. Через «Скачать» любой пользователь может выбрать предмет и получить файл в чат.

Каждая строка списка в `subjects.json` обозначает предмет, например `["Математика", "Физика"]`. После изменения списка перезапустите бота. Первая загрузка создаст папку `materials/<предмет>/`. Можно также добавить файлы в эту папку непосредственно на GitHub. Материалы в публичном репозитории доступны всем. Одноимённые файлы бот не перезаписывает.

## Запуск

Установите зависимости командой `python -m pip install -r requirements.txt` (Python 3.10+). В переменных окружения процесса задайте:

- `TELEGRAM_BOT_TOKEN` — токен бота от BotFather.
- `GITHUB_TOKEN` — fine-grained токен для CloudGGKEIT с разрешением Contents: Read and write.
- `UPLOADER_IDS` — числовые Telegram ID редакторов через запятую. При пустом значении доступно только скачивание.

Запустите `python bot.py`. Для непрерывной работы нужен постоянно работающий процесс с доступом к Telegram и GitHub. В каталоге одного предмета поддерживается до 1000 файлов (лимит GitHub Contents API).
